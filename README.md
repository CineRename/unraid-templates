# CineRename Unraid Templates

Official Community Applications repository for [CineRename](https://cinerename.app) on Unraid.

## How to add this template in Unraid

1. In Unraid, go to **Docker** > **Add Container** or install via **Community Applications**.
2. To add this template repository to Community Applications:
   - Add `https://github.com/CineRename/unraid-templates` in your Template Repositories list.
3. Search for **CineRename** and install.
